# API de Gerenciamento de Pedidos

API REST desenvolvida em Node.js com Express para o gerenciamento de pedidos de uma pequena loja, aplicando arquitetura em camadas, validação de dados e tratamento de erros[cite: 1].

## Tecnologias
- Node.js, Express, JavaScript, Jest e Supertest[cite: 1].

## Arquitetura
- **Routes (`src/routes`)**: Endpoints da API[cite: 1].
- **Controllers (`src/controllers`)**: Regras de requisição e resposta HTTP[cite: 1].
- **Services (`src/services`)**: Lógica de negócio e validações[cite: 1].

## Execução
```bash
npm install
npm run dev
